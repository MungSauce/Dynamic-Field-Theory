# Qompress Reality Gate v0.2

A working build must:

1. represent canonical primed-zero as 0x55;
2. advance/reverse chronology exactly;
3. make exactly one byte button true per position;
4. reconstruct arbitrary bytes exactly;
5. roll data and chronology fields completely back to primed-zero;
6. omit redundant unchanged-node deltas;
7. reject malformed seeds;
8. count every corpus-specific byte required by the fixed decoder.

Functional reversibility is not automatically compression. A compression claim requires the complete seed to be smaller than its source.
