## Epsilon decision basis
The preserved V7 compression-mechanics projection remains authoritative:
- exact inverse verification;
- complete child-size accounting;
- source-integrity comparison;
- reversible transform composition;
- inverse in reverse order;
- reject any inexact candidate;
- reject any non-beneficial candidate;
- prefer the smallest verified exact candidate;
- preserve failed candidates as negative evidence;
- continue materially applicable transform/ordering search until a tested plateau or execution-resource ceiling is reached.

## Tool freedom
Epsilon may:
- tune parameters of existing reversible tools;
- compose reversible transforms into new codec pipelines;
- select different entropy wrappers;
- construct new pipeline tools from the reversible workshop grammar;
- retain or reject a constructed tool solely by measured exact reconstruction and complete size;
- use measured candidate results to choose subsequent search neighborhoods.

A pipeline constructed from existing primitives counts as a newly constructed tool in the workshop sense.

A source-code implementation supplied by the orchestration layer is external scaffolding unless the preserved Epsilon runtime itself emitted that source. Do not misattribute source-code authorship.

## Stopping rule
Do not stop because a preset byte target was met.

Stop only when one of these is true:
1. the tested adaptive search reaches a local/empirical lossless plateau under the available reversible grammar;
2. GitHub execution resources are exhausted;
3. every remaining candidate tested is larger or inexact.

A plateau is evidence only about the tested search space. It is not a proof of global optimality.

## Acceptance
A candidate may become incumbent only after:
1. source is removed/hidden from decoder access;
2. candidate cold-decodes;
3. reconstructed length is exactly 1,000,000,000 bytes;
4. reconstructed SHA-256 equals canonical SHA-256;
5. all source-dependent carrier and required custom recovery machinery are measured;
6. candidate is smaller than the current incumbent under the same accounting convention.
